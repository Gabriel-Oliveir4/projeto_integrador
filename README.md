# Clínica

Sistema de gestão clínica para fisioterapeutas. Permite cadastro de pacientes, planos de tratamento, sessões e acompanhamento de exercícios.

## Tecnologias

- [Next.js 15](https://nextjs.org/) — frontend e backend
- [MongoDB Atlas](https://www.mongodb.com/atlas) — banco de dados
- [Mongoose](https://mongoosejs.com/) — modelagem de dados
- [shadcn/ui](https://ui.shadcn.com/) — componentes de interface
- [Tailwind CSS](https://tailwindcss.com/) — estilização

## Funcionalidades

- Autenticação de fisioterapeutas (cadastro e login)
- Cadastro e gestão de pacientes
- Planos de tratamento com exercícios
- Agendamento e condução de sessões
- Geração de prontuário em PDF
